# ADPF — Complete interactive customer prototype

Open index.html as the single entry point. START.html is the design index; SCREEN-COVERAGE.html lists all 52 screen destinations in English and Arabic (104 entry pages).

## Features retained and restored
The original Capture workflow has not been replaced. Its intake queue, batch and individual indexing, dossier grouping, shared and per-file metadata, retention register details, validation and submission are restored as live local forms. Upload/drop local files, preview PDF/images, select scanned pages or a device camera where supported, import actual Excel/CSV/JSON metadata, save a draft and reach a submission receipt. Submitted items appear in the operational pending list.

The original My Files browsing/transfers, project and delegation forms, integration setup wizard, workflow administration, document metadata/versions/audit/access, sharing requests and workflow inbox are also restored through the compiled local workflow engine. All screen navigation has an implemented destination. Supporting actions are local demonstrations; connections and authentication do not contact external systems.

## Customer improvements preserved
The attention-first operational dashboard, clickable KPIs, task ageing/SLA states, lifecycle queues, classification correction, search filters, management periods/trends and department/user drill-downs remain. The KPI cards retain the approved pale background, thin emerald top edge and beige growth arc. Clicking a KPI opens its actual destination page.

## New UX entry pages
Upload, scanned-page intake, metadata import, batch indexing, individual indexing, capture drafts, confirmation, project workspace, integration setup, workflow editor, activity/audit, sign-in, help and the full workflow inbox. Each has an Arabic counterpart.

## Local data and limits
The operational sample dataset is fixed to 28 October 2026. Original workflow fixtures are retained for the supporting screens. Capture Batches counts the intake batch queue; record KPIs count their matching operational records. The shared browser package store carries local form changes and captured records between journeys. Actual selected file objects are only available in their current browser session; there is no server upload, immutable audit service, real scanner/OCR integration, external sharing or actual record destruction.

Fonts, rounded icons, the original workflow runtime and the Excel metadata reader are bundled locally with applicable licenses. No framework download or installation is needed.

## Strict customer-comment implementation
CUSTOMER-COMMENTS.html maps each accepted comment to its implemented screen. Dedicated attention, overdue, exceptions, lifecycle, classification, recent archive, department, user and periodic-report pages are added. Report type joins period, department and officer parameters; exports respect the selected report area. Classification scheme, retention register, legal-hold management and disposition committee controls are preserved.
