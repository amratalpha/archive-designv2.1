A focused, consistent workspace

A single dark jade header anchors every page. Clean white workspaces, clear navigation and restrained green accents keep the focus on your documents. Switch to العربية for the matching Arabic layout.

About this review set

Officer, search, lifecycle, classification and reporting pages now demonstrate functional local drill-downs, filters, review actions and CSV exports. Data is illustrative. The original supporting workflows are restored as a live local runtime, including document capture, batch indexing, My Files, projects, delegations, integration setup and administration. See the implementation scope for live-system requirements. The supplied color palette is retained, with Roboto for English and Noto Kufi Arabic for Arabic as requested. Both font families and the rounded icons are included for offline viewing.
